# Тестирование автоматической генерации Excel отчётов

## Предварительная проверка

1. Убедитесь, что backend сервер запущен:
   - Откройте в браузере: http://localhost:3000/api/health
   - Должен вернуть: `{"ok":true,"time":"..."}`

2. Убедитесь, что фронтенд доступен:
   - Откройте в браузере: http://localhost:3000
   - Должна загрузиться страница WareCore Reports

## Тестовый сценарий

1. **Откройте вкладку "Генератор Excel отчётов"**

2. **Выберите период смены:**
   - Начало смены: `2026-07-27T00:00`
   - Окончание смены: `2026-07-27T23:59`

3. **Нажмите кнопку "Загрузить из БД"**
   - Должен появиться статус: `✅ Загружено: ошибок X, отгрузка Y, приемка Z, паллет N`
   - Секция "Отчёт по ошибкам штабелеров" должна заполниться данными
   - Секция "Отгрузка" должна заполниться строками с КИС
   - Секция "Приемка" должна заполниться строками с КИС
   - Секция "Паллеты" должна заполниться статистикой

4. **Проверьте данные:**
   - В "Отчёте по ошибкам штабелеров" должны быть строки с временными метками и статусами F06
   - В "Отгрузке" должны быть строки с номерами КИС и количеством паллет
   - В "Приемке" должны быть строки с номерами КИС и количеством паллет
   - В "Паллетах" должны быть подсчитаны парные и непарные паллеты

5. **Нажмите кнопку "Загрузить и скачать 2 файла"**
   - Должен скачаться файл `stackers_report.xlsx` (отчёт по ошибкам штабелеров)
   - Должен скачаться файл `shift_report.xlsx` (отчёт смены)

6. **Проверьте скачанные файлы:**
   - Откройте `stackers_report.xlsx` — должны быть данные об ошибках штабелеров с цветовой маркировкой
   - Откройте `shift_report.xlsx` — должны быть данные об отгрузке, приемке, ошибках и паллетах

## Ожидаемые результаты

- Все данные загружаются автоматически из БД
- Формат данных соответствует существующему формату отчётов
- Excel файлы генерируются корректно
- Статистика ВОТС рассчитывается автоматически

## Если что-то не работает

1. **Backend не запущен:**
   - Запустите `server/start-server.bat`
   - Проверьте, что порт 3000 не занят

2. **Данные не загружаются:**
   - Проверьте адрес backend в настройках (разверните "Адрес backend-сервера")
   - По умолчанию: `http://localhost:3000`
   - Проверьте логи в термиале сервера

3. **Excel файлы не скачиваются:**
   - Проверьте, что данные загружены в таблицы
   - Проверьте, что браузер разрешает скачивание файлов
