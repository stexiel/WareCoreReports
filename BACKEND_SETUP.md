# WareCore Reports — Backend Server

Backend-сервер для автоматической загрузки данных из баз WMS_1386 и WCS_1386 в генератор Excel отчётов.

## Установка

1. Установите Node.js (если не установлен): https://nodejs.org/
2. Откройте терминал в папке `server` и выполните:
   ```bash
   npm install
   ```

## Запуск сервера

### Ручной запуск
```bash
cd server
node server.js
```
Или дважды кликните на `start-server.bat`

Сервер запустится на порту 3000 и будет доступен по адресу: http://localhost:3000

### Автозапуск при старте Windows

1. Запустите `install-autostart.bat` **от имени администратора**
2. Сервер будет автоматически запускаться при старте системы
3. Для отключения автозапуска запустите `uninstall-autostart.bat` от имени администратора

## Использование

1. Откройте в браузере: http://localhost:3000
2. Перейдите на вкладку **"Генератор Excel отчётов"**
3. В блоке **"⚡ Автозагрузка данных из БД"**:
   - Выберите **Начало смены** и **Окончание смены**
   - Нажмите **"Загрузить из БД"** — данные автоматически заполнятся
   - Или нажмите **"Загрузить и скачать 2 файла"** — загрузка и автоматическое скачивание отчётов

## API Эндпоинты

- `GET /api/fault-report?from=...&to=...` — ошибки штабелеров (WCS_1386)
- `GET /api/shipment?from=...&to=...` — отгрузка (WMS_1386)
- `GET /api/receipt?from=...&to=...` — приёмка (WMS_1386)
- `GET /api/pallets?from=...&to=...` — паллеты D1/D2 (WMS_1386)

Параметры:
- `from` — начало периода (ISO формат: `2026-07-27T00:00`)
- `to` — окончание периода (ISO формат: `2026-07-27T23:59`)

## Настройка подключения к БД

Файл `server/.env`:
```

DB_USER=readonly_user
DB_PASSWORD=Read123!Pass@
DB_PORT=1433

```

## Решение проблем

### Сервер не запускается
- Проверьте, что Node.js установлен: `node --version`
- Проверьте, что порт 3000 не занят другим приложением
- Проверьте подключение к SQL Server (пинг до 172.30.1.10)

### Данные не загружаются
- Проверьте, что backend сервер запущен (http://localhost:3000/api/health)
- Проверьте адрес backend в настройках фронтенда (разверните "Адрес backend-сервера")
- Проверьте логи в термиле сервера

### Автозапуск не работает
- Запустите `install-autostart.bat` от имени администратора
- Проверьте Task Scheduler: найдите задачу "WareCore Backend Server"
